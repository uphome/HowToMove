# L0 单步学习报告

> 日期：2026-11-16 ｜ 阶段：L0 空地单步 ｜ 模型：Qwen3-0.6B + LoRA
> 数据：balanced L0 + natural L0 ｜ 训练：10 updates ｜ 评估：greedy

---

## 1. 阶段目标

L0 是分阶段学习的第一阶段，只验证最基础的**方向接地**：

> 给定当前状态，模型能否从 up / down / left / right 中选出一个让 BFS
> 距离减 1 的动作。

这一阶段**不要求**：

- 多步规划；
- 绕墙；
- U 型墙；
- 从 start 完整走到 goal。

L0 的目标是把「当前状态 → 方向」这一步做稳，再进入 L1 带墙单步。

---

## 2. 数据与评测口径

### balanced L0

| split | 总数 | singleton | mixed |
|---|---:|---|---|
| train | 320 | 每个方向 64 | 每个组合 16 |
| val | 64 | 每个方向 12 | 每个组合 4 |
| test | 64 | 每个方向 12 | 每个组合 4 |

- singleton：`singleton_up/down/left/right`
- mixed：`mixed_dr/dl/ur/ul`
- 每个状态带 `optimal_actions`，由 BFS 距离场计算；
- test 只用于最终报告，不参与早停或选模。

### natural L0

`data/eval_states.jsonl` 里的 60 条原始状态，不做动作均衡，作为真实分布对照。

### 指标

- `balanced test optimal`：主指标；
- `natural test optimal`：辅助指标；
- `up/down/left/right singleton accuracy`：方向接地指标；
- `valid rate`：格式护栏；
- `degenerate rate`：还有没有 GRPO 梯度信号。

评测统一使用 greedy 解码。

---

## 3. 训练配置

```text
base: Qwen3-0.6B
adapter: LoRA, r=16, alpha=32
lr: 5e-5
states/update: 16
G: 8
temperature: 1.2
max_tokens: 40
updates: 10
eval_every: 5
seed: 7
```

---

## 4. 三组观测

| 组 | `--obs-style` | 说明 |
|---|---|---|
| A | `minimal` | 绝对坐标 `pos/goal/walls` |
| B | `rel` | 全局相对坐标：goal delta、相对墙、bounds |
| C | `rel + few-shot` | B 的格式 + 4 条 cardinal 示例 |

相对格式：

```text
map 12x12, x=right y=down, origin=you
goal: delta=(-7,+2)
bounds: left=7 right=4 up=1 down=10
walls_rel: none
```

C 组在 system + few-shot 里给出：

```text
delta=(0,+3)  -> down
delta=(0,-3)  -> up
delta=(+3,0)  -> right
delta=(-3,0)  -> left
```

C 的 prompt 约 **594 tokens**，仍在 1024 以内。

---

## 5. 结果

| 指标 | A absolute | B relative | C relative + few-shot |
|---|---:|---:|---:|
| balanced test baseline | 65.62% | 31.25% | 73.44% |
| **balanced test @10** | **89.06%** | **31.25%** | **100.00%** |
| natural test @10 | 96.67% | 55.00% | 93.33% |
| valid | 100% | 100% | 100% |
| degenerate @10 | 68.75% | 100% | 93.75% |

### A：absolute

- balanced test 65.62% → 89.06%；
- natural 81.67% → 96.67%；
- baseline 的 down singleton 是 0%，训练后到 100%；
- 但 up singleton 最后约 75%，仍有方向偏置；
- 只有 16 个 mixed 状态，模型主要靠水平/垂直方向混合通过。

### B：relative 无 few-shot

- balanced test 31.25% → 31.25%；
- natural 55.00% → 55.00%；
- 64/64 个 balanced test 状态全部输出 `right`；
- 组内动作无差异，advantage 全 0，GRPO 完全学不动；
- 结论：0.6B 不能直接理解裸 signed-delta 相对格式。

### C：relative + few-shot

- zero-shot 就已经达到 balanced 73.44%、natural 86.67%，动作分布覆盖 up/left/right/down；
- 10 updates 后 balanced test **100%**；
- 四个 singleton 方向最终都是 100%；
- natural 93.33%；
- 但 degenerate 到 93.75%，L0 已经饱和。

---

## 6. L0 是否完成

建议的 L0 完成标准：

1. balanced test optimal ≥ 90%；
2. natural test optimal ≥ 90%；
3. 四个 singleton 方向都 ≥ 90%；
4. valid ≥ 99%；
5. degenerate 高说明 L0 已饱和，应停止继续堆 L0。

按这个标准：

- **A absolute**：natural 达标，balanced 89.06% 接近；但 up 75% 不满足四方向标准；
- **B relative**：完全不达标；
- **C relative + few-shot**：balanced 100%、natural 93.33%、四方向 100%，满足 L0 完成标准。

结论：

> L0 的方向接地已经基本解决。C 组在 balanced 上完成度最高；
> A 组仍然是一个强 baseline，但 up 方向不够稳。
> 下一阶段应进入 L1，而不是继续训练 L0。

需要注意：C 的 100% 是 64 条 balanced test、单 seed 上的结果，
统计上仍然偏乐观；正式 L1 前建议扩大 eval 或增加 seed 复测。

---

## 7. 关键发现

1. **natural optimal 会掩盖 down 偏置**
   - L0 自然分布里斜对角 mixed 状态占多数；
   - 只看 natural，模型可以一直选 left/right 也拿到很高分；
   - 必须看 balanced test 和 singleton accuracy。

2. **相对坐标本身可行，但需要 few-shot**
   - 裸 signed-delta 格式模型直接退化成常量 `right`；
   - 4 条 cardinal few-shot 就能让模型建立 dx/dy → 动作的映射；
   - few-shot 后 GRPO 才能产生有效梯度。

3. **L0 很快饱和**
   - C 组最后 degenerate 93.75%；
   - 继续训练 L0 的收益很低；
   - 应尽快进入 L1 带墙单步。

---

## 8. 局限

- balanced test 只有 64 条；
- 单 seed；
- 没有 OOD（8×8 / 16×16）；
- 没有多步；
- 没有 SFT，few-shot 只是 prompt 内示例；
- L0 空地不能证明绕墙能力。

---

## 9. 下一阶段 L1

建议：

- 使用 `data/states` 的 L1 状态集；
- 保持同样的评测口径：balanced val/test + natural + per-direction；
- 先用 C 的相对格式 + few-shot，增加墙的相对示例；
- 对照 A absolute，观察相对坐标是否真的带来泛化优势；
- L1 的目标是「带墙单步方向接地」，仍不做多步。
