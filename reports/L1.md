# L1 单步学习报告

> 日期：2026-11-16 ｜ 阶段：L1 带墙单步 ｜ 模型：Qwen3-0.6B + LoRA
> 数据：balanced L1 + natural L1 ｜ 训练：20 updates ｜ 评估：greedy

---

## 1. 阶段目标

L1 在 L0 的基础上加入单面墙，仍然只做**单步方向接地**：

- 给定当前状态（含墙）；
- 选一个让 BFS 距离减 1 的动作；
- 不做多步，不做完整路径规划。

L1 主要新增难点：

- 墙的坐标/相对位置需要被模型理解；
- 某些方向会被墙挡住；
- 斜对角 mixed 状态之外，单方向状态更多。

---

## 2. 数据与评测

### balanced L1

| split | 总数 | singleton | mixed |
|---|---:|---|---|
| train | 320 | 每个方向 64 | 每个组合 16 |
| val | 64 | 每个方向 12 | 每个组合 4 |
| test | 64 | 每个方向 12 | 每个组合 4 |

### natural L1

`data/eval_states.jsonl` 中 60 条 L1 状态。

评测沿用实验协议：

- greedy；
- val 用于 best/早停；
- test 只做最终报告；
- natural 作为辅助对照；
- 主指标：balanced test optimal；
- 方向指标：singleton accuracy。

---

## 3. 训练配置

```text
base: Qwen3-0.6B
adapter: LoRA r=16
lr: 5e-5
states/update: 16
G: 8
temperature: 1.2
max_tokens: 40
updates: 20
eval_every: 5
seed: 7
```

两组都跑满 20 updates，不早停，保证可比。

---

## 4. 观测对照

| 组 | 观测 |
|---|---|
| A | `minimal` 绝对坐标 |
| B | `rel + few-shot`（`rel_l1`，含两条带墙示例） |

L1 的 `rel_l1` few-shot 在 L0 的四条 cardinal 示例之外，增加了：

- 一个带墙的 down 示例；
- 一个带墙的 left 示例。

平均 prompt 长度约 828 tokens。

---

## 5. 结果

| 指标 | A absolute | B rel + few-shot |
|---|---:|---:|
| balanced test baseline | 54.69% | 51.56% |
| balanced test best | 65.62% | **78.12%** |
| natural test best | 88.33% | **95.00%** |
| valid | 100% | 100% |
| best update | 15 | 20 |
| best val optimal | 70.31% | **82.81%** |
| final degenerate | 高 | **100%** |

### A absolute

- baseline：val 57.81% / test 54.69% / natural 73.33%；
- best 在 update 15：val 70.31% / test 65.62% / natural 88.33%；
- update 20 又回退到 test 54.69%；
- best 时方向 singleton：

```text
up    0%
down  50%
left  75%
right 100%
```

模型基本没有学会 up，动作分布里 up 消失。

### B relative + few-shot

- baseline：val 50.00% / test 51.56% / natural 65.00%；
- update 20：val 82.81% / test 78.12% / natural 95.00%；
- 最终方向 singleton：

```text
up    33.3%
down  50.0%
left  100%
right 100%
```

相对坐标 + few-shot 明显优于 absolute：

- test +12.5pp；
- natural +6.7pp；
- up 从 0% 提升到约 33%；
- left/right 基本解决；
- down 仍停在 50%。

但 B 最后 degenerate 100%，最后一条 update 的训练 `samples=0`，
说明训练组已经几乎全部无区分度，继续堆 L1 update 不会自然解决 up/down。

训练状态与 eval 状态也出现明显 gap：最后训练组 singleton 约
up 66.7% / down 100% / left 100% / right 100%，但 balanced test
仍然是 up 33.3% / down 50%。模型更像是在拟合训练状态，而不是学会了
完整的四方向墙内接地。

---

## 6. 是否达到 L1 完成标准

协议中 L1 建议标准：

```text
balanced test optimal >= 80%
natural test optimal >= 80%
四个 singleton >= 75%
valid >= 99%
```

对照：

- A：test 65.62%，up 0%，不达标；
- B：natural 95%、valid 100%，但 test 78.12%，up 33%、down 50%，不达标；
- 两组都出现高退化，L1 还没有完成。

结论：

> relative + few-shot 是明显更好的 L1 观测，但 L1 还没有完全解决。
> 当前主要缺口是 **up 和 down 单方向状态**，不是格式，也不是整体训练链路。

---

## 7. 关键发现

1. **墙显著降低绝对坐标模型的表现**
   - L0 absolute balanced test 约 89%；
   - L1 absolute best 只有 65.62%；
   - 模型在 L1 上更容易退化成水平方向。

2. **relative + few-shot 在 L1 仍然有效**
   - test/natural/up/left/right 都优于 absolute；
   - few-shot 的带墙示例没有破坏格式，反而帮助模型读 `walls_rel`。

3. **up/down 是当前瓶颈**
   - 最终 up 33%、down 50%；
   - 训练动作分布也几乎不输出 up；
   - 说明数据覆盖或采样不足，不能只靠继续训练解决。

4. **L1 在 20 updates 后已经饱和**
   - degenerate 到 100%；
   - best 已经出现在最后一个 eval 点；
   - 再跑更多 update 收益很低。

---

## 8. 局限

- balanced test 64 条，单 seed；
- per-direction 只有 12 条 singleton；
- 没有 OOD；
- 没有 SFT；
- 相对 few-shot prompt 约 828 tokens，成本高于 absolute；
- 训练采样仍是状态串行、组内 G 并行。

---

## 9. 下一步

不建议直接进入 L2。L1 还差 up/down，建议先做 L1.5：

1. 针对 up/down 单方向状态做**类别均衡采样**；
2. 增加 up/down 的 few-shot 示例和 wall 示例；
3. 检查 `walls_rel` 的排序/符号是否让 up/down 更难；
4. 如果仍然学不会，再考虑 SFT 冷启动；
5. 等 L1 达到 test ≥80%、四方向 ≥75% 后再进入 L2。
